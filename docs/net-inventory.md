### Executed dispositions (ledger appended 2026-08-14)

Every disposition proposed against the 2026-07 baseline (`d8dd513`) has been
executed.  The tables above are the post-execution scan; what changed:

1. **Embed GGUF auto-download → brokered.**  The old raw
   `urlopen(EMBED_MODEL_URL)` site is gone.  `serving.py` now fetches the
   nomic GGUF through `amiga_net.broker` under a `huggingface` lease
   (`broker.lease("embed model (first start)") → broker.download(...)`).
   The `serving.py` EXTERNAL row remaining in P3 is the URL *literal*
   (`EMBED_MODEL_URL`), consumed only by the broker call.
2. **Engine weight downloads → inverted (B-14/B-15).**  Engines launch with
   `HF_HUB_OFFLINE=1`, `TRANSFORMERS_OFFLINE=1`, `VLLM_NO_USAGE_STATS=1`,
   `VLLM_DO_NOT_TRACK=1`; weights arrive beforehand via
   `python3 -m knowledgehost pull` (`amiga_net/pull.py`) under lease, and the
   broker-pulled model store outranks the legacy hub cache.  Container images
   pull under the broker's container-images rule.
3. **Model search → brokered.**  `modelfind.py` runs its huggingface catalogue
   search as a leased `broker.request`, same audit trail as pull.
4. **Concurrent transfers serialized.**  `downloads.py` queues pulls
   one-at-a-time (the lease file is one per rule; two concurrent pulls would
   revoke each other).
5. **Loopback/LAN dynamic calls** (distill / embed / rerank / metrics `urlopen`
   on cfg URLs): kept, loopback by default, per the amended B-3 disposition.
